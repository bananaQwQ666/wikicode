# 龙渊档案馆·异界志·卷一

> 初代城主遗留的异界之窗数字化档案。

## 异界概述

龙泉，异界之一处，其西街与龙渊城西街同名同魂。初代城主曾以此"异界之窗"法器窥见其景。
