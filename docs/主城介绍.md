# 主城介绍

龙渊市：蕉元2453年，一颗突如其来的小行星朝着地球飞来，砸向了地球上星辰市的太空港。顿时，以星辰市为中心的广大范围都化作废墟，同时，灾区四处出现了一种神秘力量，相关机构曾展开研究，经过多年的努力，神秘力量于2484年被基本控制。龙渊城刚好位于灾区边界，又由，这里本就有丰富的历史文化，以及一定的发展基础，于是人们在这里建立了新城，接纳灾区幸存难民。蕉元2504年，小蕉接手了龙渊城的管理事务，在小蕉上任后，龙渊城的发展达到了一个新的高度，并重新兴起了一些已经荒废的事业，建立了许多便民娱乐设施，并建立龙渊最大的互联网经济开发区互联网城。与其余的几个新城(清湖市、客城市、辽原市、蜀山市、燕京市、长安市、湖中特别行政区、藏源市)共同推动发展。

==龙渊市的现实原型是浙江省丽水市龙泉市，以宝剑、青瓷闻名，有著名的龙泉剑、哥窑青瓷等，冰裂纹是龙泉青瓷的一个品种。长三角第一高峰黄茅尖(1929m)也坐落在龙泉。龙泉还是网络小说《剑来》的原型地，服主欢迎大家来龙泉游玩awa==

### 金融中心(左)和游戏厅(右)
![金融中心(左)和游戏厅(右)](/img/hp8UMoE1tzXKs-DS/1761404529697-e209127d-652d-40d8-9960-be1c39576f5e-418158.png)

金融中心是全市金融的命脉，这里有着多家金融公司，维持整个城市的金融体系

游戏厅是市民与玩家的娱乐场所(暂时没有实际用途，但是未来会更新)

### 探险者之家(下)和竞技场(上)
![探险者之家(下)和竞技场(上)](/img/hp8UMoE1tzXKs-DS/1761404737878-84dbb2d3-66b3-4d9e-bcdb-169c3ec42f96-294797.png)

探险者之家：2507年，全国探险家数量急剧上升，为了接待到更多的探险家，服主小蕉特意成立了该机构，为探险家们提供各种服务。如果你在探险的过程中有困惑，在这里你或许可以寻找到答案。

竞技场：普通公会战、赛季公会战都会在这里进行，详见“玩法教程”中的“公会系统”页面

### 龙渊塔
![龙渊塔](/img/hp8UMoE1tzXKs-DS/1761406156404-25610af6-b619-4329-9497-998d9f9d38ca-255422.png)

龙渊标志性建筑，高约100格，在互联网城和游戏厅等建筑竣工前为龙渊最高建筑，由“专业”设计师设计。你真的可以登上顶楼看看哦！

“西街”原型为龙泉市西街街道的西街，在这里直接引用现实中对细节的描述：==唐乾元二年(公元759年)置龙泉县时，西街就已存在，其兴盛与龙泉青瓷有着千丝万缕的联系，古时被称为“瓷街”，瓷号众多，整船的龙泉青瓷由此经龙泉溪水运至温州，销往海内外。如今(21世纪)，龙泉对西街的开发仍在继续，漫步在新西街，看着夜晚的灯光，真的仿佛来到了一个赛博古城。此外，西街三江口还有一颗很有特点的大树，在《剑来》中，它不仅是骊珠洞天的守护者，更是四姓十族先祖英灵的化身。感兴趣的朋友有机会可以来“圣地巡礼”。==
