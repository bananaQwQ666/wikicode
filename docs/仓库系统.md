# 仓库系统

### 进入仓库系统的方式
按下<font style="background-color:#ff5847;">Shift+F或者输入/cd</font>打开服务器菜单，随后左键点击<font style="background-color:#ff5847;">第二行第二个</font>即可进入，右键点击则是切换是否自动拾取(请注意聊天框提示)。

![第二行第二个的潜影盒图标就是仓库系统](/img/vdKrI-3busu0B_zF/1755334789775-fe7324f6-bb65-4d0d-8c17-3cce2e53e210-606013.png)

### 如何获得仓库
![仓库菜单的主界面](/img/vdKrI-3busu0B_zF/1755334915462-6b80d5c2-d2b6-4bb6-9a3a-2ad8ddc627c5-426303.png)

当你第一次进入服务器时，你是一个仓库都没有的，那么如何获得仓库呢？

您需要前往<font style="background-color:#ff5847;">主城商店一楼</font>的仓库商店<font style="background-color:#ff5847;">购买仓库兑换券</font>，<font style="background-color:#ff5847;">手持兑换券右键</font>，您就成功获得了一个仓库，随后就可以往里面存东西了

| **仓库类型** | **仓库大小** | **仓库价格** |
| --- | --- | --- |
| 中仓库 | 27格(中箱子) | 400蕉币/个 |
| 大仓库 | 54格(大箱子) | 600蕉币/个 |
| 共享仓库(后文有讲) | 36格(4行) | 1点数(600蕉币)/个 |




<font style="background-color:#ff5847;">左键</font>打开仓库，<font style="background-color:#ff5847;">右Shift+右键</font>可以修改仓库名称

每个人最多能拥有30个大仓库(每个为54格，即一个大箱子的空间)

以及30个中仓库(每个为27格，即一个小箱子的空间)

### 物品搜索
仓库主界面第一页左上角的<font style="background-color:#ff5847;">粉色玻璃</font>，点击进入

![仓库系统搜索页面](/img/vdKrI-3busu0B_zF/1755335201971-fa6c46f3-700e-48da-86fc-5ef752d0ba7a-004099.png)

命名牌为是否在物品名称内搜索，展示框为是否在物品Lore(即下方的描述)中搜索，只需鼠标放在上面<font style="background-color:#ff5847;">点击左键</font>就可以切换。<font style="background-color:#ff5847;">点击右边的钻石镐</font>，在<font style="background-color:#ff5847;">聊天框中输入</font>需要搜索的关键词并<font style="background-color:#ff5847;">按下Enter</font>即可搜索，输入<font style="background-color:#ff5847;">#</font>即取消搜索。

![按下搜索键后聊天框的提示](/img/vdKrI-3busu0B_zF/1755335331363-05fdb625-9961-4919-9ae7-5c9e2652e947-100567.png)

### 共享仓库的创建和使用
玩家创建共享仓库需要<font style="background-color:#ff5847;">消耗仓库点数</font>，仓库点数也需要到<font style="background-color:#ff5847;">主城商店一楼</font>的仓库商店购买，有了仓库点数后，点击仓库主界面右上角的<font style="background-color:#ff5847;">橙色玻璃</font>进入共享仓库页面，左键点击<font style="background-color:#ff5847;">左上角的绿色玻璃</font>进行创建![共享仓库页面](/img/vdKrI-3busu0B_zF/1755335632175-a5b2563c-e936-474d-a43e-015ae90e9758-307600.png)

![创建了一个共享仓库](/img/vdKrI-3busu0B_zF/1755335689228-aae22511-21b2-44dc-b157-6867913201b5-938972.png)

创建后，对着你创建的共享仓库左键即可进入仓库，右键即可对成员进行管理

![仓库设置](/img/vdKrI-3busu0B_zF/1755335781288-39bb283b-815c-4309-bbaa-0b230e200cb1-666615.png)

最左侧一排，左键第一个<font style="background-color:#ff5847;">橙色玻璃</font>，在聊天框中输入想要邀请的玩家ID(对方需在线)，对方即可收到邀请。<font style="color:#DF2A3F;">红色玻璃为删除仓库</font>。

![收到了邀请](/img/vdKrI-3busu0B_zF/1755335898564-6506eedc-b397-4a05-9324-955cf16bca37-417089.png)

对方打开聊天框以后，<font style="background-color:#ff5847;">直接点击</font>接受或拒绝即可



对方接受您的邀请之后，您就可以在仓库设置页面设置成员的权限

![给成员设置权限](/img/vdKrI-3busu0B_zF/1755335992659-b033c709-f16d-4e2d-9f7c-1c4ddc994c2b-683898.png)

权限的分布如下，根据需求设置。设置完别忘了左键点击左下角的<font style="background-color:#ff5847;">绿色玻璃</font>进行保存。

![权限分布](/img/vdKrI-3busu0B_zF/1755336015413-e161a89d-b4de-4cc8-adb1-891285401def-868993.png)

| **权限等级** | **权限内容** |
| --- | --- |
| 低 | 可访问共享仓库第一行 |
| 中 | 可访问共享仓库第一、二行 |
| 高 | 可访问共享仓库第一、二、三行 |
| 超高 | 可访问共享仓库全部行列 |
