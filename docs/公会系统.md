# 公会系统

![菜单中的公会系统选项](/img/ok9020nMU0n0j6Rr/1755347110623-4e04d183-f892-4484-adaa-4aca01ba82a1-168046.png)

打开服务器菜单后，左键点击<font style="background-color:#ff5847;">第三行最中间</font>的一个人像图标，即可进入公会系统页面

![公会列表](/img/ok9020nMU0n0j6Rr/1755347304275-05cb26ed-5064-4247-885b-03cb36dfcd23-885872.png)

这里会列出服务器内的所有公会，可以通过最底下一行的两个磁力诱饵图标翻页。在此界面，寻找到自己中意的公会，鼠标左键点击即可<font style="background-color:#ff5847;">申请加入该公会</font>，由会长同意即可成功加入。

指南针是“根据类型搜索”，左键点击即可<font style="background-color:#ff5847;">切换搜索类型</font>

### 如何做一个合格的公会成员
成功加入一个公会以后，就可以来到公会列表界面，点击<font style="background-color:#ff5847;">最底下一行</font>的玩家头颅进入“我的公会”页面

![普通公会成员的“我的公会”页面](/img/ok9020nMU0n0j6Rr/1755350889420-0304a8b0-9a7b-4062-8fe2-8c90bef0b12d-577359.png)

接下来，你们就需要了解了解上面11个按钮(苹果不是按钮)的功能

**公会公告**——会长可以向公会成员发布公告，可能会是一些重要的事情，或者是活动通知，你作为一个公会成员，一定要时刻关注着自己公会的通知！

**回到主城**——这里的主城并非服务器主城，而是会长设置的公会主城，它通常是个公会城议事中心、公会城广场、公会城大厅等等，当然，具体位置还是听你会长的。

**成员列表**——当然要弄清楚自己所在的公会有哪些小伙伴啦！

**公会任务**——这里面的任务是需要所有公会成员共同完成的！（暂时还没有任务，因为服主太忙了，还没有设置任务![1755353204330-fd8280d8-7592-45cf-b68f-1cd0b72715ea.png](/img/ok9020nMU0n0j6Rr/1755353204330-fd8280d8-7592-45cf-b68f-1cd0b72715ea-541480.png)）

**公会签到**——每天使用100金币进行签到，可以获得贡献值。

**公会商店**——你的会长说不定会在这里面买许多好东西呢！

**公会银行**——签到获得的贡献值可以捐给公会，转化为公会资金，能给会长用来给公会升级。

**公会神石**——支付贡献值来挖掘公会矿石，获得的公会矿石可以给会长用来给公会成员升级公会BUFF。将公会资金支付给公会神石，可以升级公会神石，能够增加活跃效率。

**公会称号**——随着公会的升级，公会称号也会进行升级，装备上公会称号还可以获得BUFF哦！

**公会活动**——在里面可以为公会报名公会战，分为赛季公会战和匹配公会战。平时可以报名进行匹配公会战。每周六19:00展开赛季公会战，所以在周六那一天无法报名匹配公会战。公会战会提供道具，无需自备。

**退出公会**——你要抛弃你的公会吗？



### 如何自己创建一个公会
只需点击公会列表页面<font style="background-color:#ff5847;">最底下一行</font>的玩家头颅，即可创建公会。点击后，系统会要求你在<font style="background-color:#ff5847;">聊天框输入</font>想要的公会名(不能违规)，输入完毕后，<font style="background-color:#ff5847;">回车</font>便会进入支付页面，左边的点券支付不用管，因为本服根本就没有点券系统。直接点击右边的金币支付，<font style="background-color:#ff5847;">花5000蕉币</font>就可以完成创建。

![成功创建公会的提示](/img/ok9020nMU0n0j6Rr/1755348274552-ecd6437c-47a7-4362-8c49-a1a9eb01b138-172631.png)

### 如何管理自己的公会
创建完自己的公会后，再次打开公会列表页面，原本的创建公会按钮会变为“我的公会”，点击即可进入自己公会的界面。

![会长的“我的公会”页面](/img/ok9020nMU0n0j6Rr/1755352015035-78a8e71b-2618-4a0b-874f-d44c97500b7d-213905.png)

点击<font style="background-color:#ff5847;">最顶上的绿宝石</font>，即可进入管理页面

![公会管理页面](/img/ok9020nMU0n0j6Rr/1755352063702-9bfd065a-1e99-47df-ba78-7c475e834b27-249380.png)

接下来，会长需要了解上面12个按钮(苹果不是按钮)的功能

**公会升级**——你需要成员们每日签到获得贡献值，并且将贡献值通过公会银行捐赠给公会银行转换为公会资金，才能使用公会资金来升级公会，并且要符合升级条件。

**公会改名**——使用1000公会资金(不是蕉币，不是蕉币，不是蕉币！)进行改名

**邀请成员**——可以直接邀请在线成员加入，但需要10公会资金

**公会LOGO商城、公会LOGO仓库**——暂时没有任何用处，因为服主目前还没研究出来怎么添加LOGO![1755353204330-fd8280d8-7592-45cf-b68f-1cd0b72715ea.png](/img/ok9020nMU0n0j6Rr/1755353204330-fd8280d8-7592-45cf-b68f-1cd0b72715ea-541480.png)

**公会审批**——对申请人进行审批(如果有玩家申请加入公会，且你也在线，那么你作为会长会受到以下提示)

![收到申请的提示](/img/ok9020nMU0n0j6Rr/1755351966190-bd578680-980e-493f-95c9-58ecf9128e97-007969.png)

打开聊天框，然后直接用鼠标点击对应的按钮就可以了

**设置公会主城**——只需要站在想设置为公会主城的地方，再点击它就可以成功设置了

**设置成员PVP**——开关成员间是否可以PVP，需要支付公会资金

**创建公会基地**——别看了，创不了![1755353204330-fd8280d8-7592-45cf-b68f-1cd0b72715ea.png](/img/ok9020nMU0n0j6Rr/1755353204330-fd8280d8-7592-45cf-b68f-1cd0b72715ea-541480.png)

**解散公会**——你怎么想的？

**变更描述**——花1000公会资金更改公会在公会列表页面的描述

**设置加入模式**——花100公会资金设置玩家需要通过什么方式加入



作为公会会长，你可以带领公会成员一起建立公会城镇，一起举办公会活动，一起做许多有趣的事情。我建议你们创建一个公会群，方便自己公会的事务安排，也可以看情况对公会成员进行审核。我们允许公会在服务器群里进行适度宣传，你可以自己制作宣传片、宣传图来宣传你的公会（不能刷屏），只要不违规，我们大力支持公会的发展，我们还会定期举办优秀公会评比，选出一定数量的优秀公会；如果违规了，我们会依据服务器规则处理。当然，公会之间一定要和谐相处，不要挑起对立。一定要负责任，敢于承担责任，管理好自己的公会，如果因为公会间的矛盾发生什么大问题，后果自负。
