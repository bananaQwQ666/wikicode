# 地图画

首先，你需要去网上找一个==在线图床==(如果你自己有服务器可以连接到的个人服务器，也可以)，然后上传想要做成地图画的图片，==获取图片的URL==

随后在游戏里输入以下指令(==宽和高为格数，如果不写宽和高，则会按照默认比例生成==)

> /tomap 图片URL resize 宽 高
>

![生成出来的地图，会提示需要多少展示框以及宽和高](/img/uT93HrqIBgi7uIxH/1755408562814-2341be79-7ce3-4dae-bcd3-8b5bf793534b-134308.png)

摆好所有展示框后，手持地图，右键点击==最左下角的展示框==即可放置

![放下来的地图画](/img/uT93HrqIBgi7uIxH/1755408879722-3eeb1feb-1dd9-4d1f-8ee7-886849a6f912-790963.png)
