# 坐、躺、趴、旋转

### 坐
对准一个台阶或者楼梯，右键点击可以直接坐下

在地上输入<font style="background-color:#ff5847;">/gsit</font>也可以坐下

![坐下的样子](/img/P6OD-kNSZvDoNeUm/1755409044867-a4993b8b-f373-4784-a4da-4cd70333b65f-757184.png)

### 躺
输入<font style="background-color:#ff5847;">/lay</font>即可躺下(躺下后，头会随着你视角的变化而左右摆动)

![躺下的样子](/img/P6OD-kNSZvDoNeUm/1755409093663-bd3c592a-e9c1-40cf-b521-81516934f62f-335802.png)

### 趴
输入<font style="background-color:#ff5847;">/crawl</font>即可趴下

![趴下的样子(和穿越一格的空间一样)](/img/P6OD-kNSZvDoNeUm/1755409196241-da719546-e4fd-4014-a54f-c155d0bafb3b-865684.png)

### 旋转
输入<font style="background-color:#ff5847;">/spin</font>即可旋转

![旋转的样子(和使用三叉戟时的旋转一样)](/img/P6OD-kNSZvDoNeUm/1755409250853-2163c4da-25a2-4cf8-bddc-d68e22f68572-201801.png)
