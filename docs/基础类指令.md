# 基础类指令

1. ==@别人==：在服务器中聊天时，只需输入==@玩家ID== 就可以让对方收到提醒

2. ==回到主城==：输入==/spawn==即可
3. ==挂机==：输入==/afk==即可进入挂机状态，要退出只需要再次输入该指令或者是走几步
4. ==返回上一检查点==：输入==/back==即可回到上一地点(包括传送的上一地点)，输入==/dback==回到上一死亡地点(不包括传送的上一地点)
5. ==金钱相关==：==/balance==或==/money==查看金钱数量，==/baltop==查看全服金钱排行榜，手持一张纸并输入==/cheque 金钱数量== 将金钱转化为支票，==/pay 玩家名字 金钱数量== 可以给指定玩家打指定的金钱
6. ==打开末影箱==：输入==/ender==即可
7. ==戴帽子==：手持一个物品，输入==/hat==就可以把这个物品戴到自己头上
8. ==设置家相关==：==/sethome 家的名字== 即可把脚下设置为自己家的传送点(可以设置多个家)，==/homes==在GUI里查看自己设置的家，==/home 家的名字== 传送到对应的家，输入==/delhome 家的名字== 可以移除这一个家
9. ==查看延迟==：输入==/ping==即可
10. ==随机传送==：输入==/rt==即可在当前世界内随机传送，但不要在主城用，否则后果自负
11. ==传送请求==：输入==/tpa 玩家名== 可以向该玩家发送传送请求，只需对方同意就可以传送过去。输入==/tpahere 玩家名== 可以请求该玩家传送到自己这里，只需要对方同意他就可以传送过来。当别人给你发送传送请求时，可以输入==/tpaccept==接受或者==/tpdeny==拒绝
12. ==地标==：输入==/warp 地标名== 可以传送到已设置的地标，输入==/warps==可以查看已设置的地标列表
