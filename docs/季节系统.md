# 季节系统

服务器安装了真实季节系统，不同季节下，树叶颜色、草地颜色等等都会不一样，冬季还会下雪，河流冰封。

而且，季节还与星露谷种植系统相联动，星露谷种植系统每个作物都有适宜种植的季节，需要根据世界的季节来进行种植，如果不处于作物适宜的季节，是无法种植的(也可以购买温室玻璃，放在田地上方，这样就什么季节都可以种了，详细介绍请见“星露谷种植和钓鱼系统”这篇文章)

那么，如何查看该世界处于什么季节呢？很简单，只需要打开服务器菜单，点进<font style="background-color:#ff5847;">第一行中间的“我的”</font>

![服务器菜单中的“我的”](/img/bsJOLZHsEK2Dkm49/1755407653443-ead9d064-6c4a-473f-9fc3-f0137b21c540-307570.png)

然后在<font style="background-color:#ff5847;">第一行的“此世界的季节”</font>里就可以看见当前这个世界的季节了(目前，只有生存一区和资源世界开启了季节系统)
