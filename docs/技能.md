# 技能

![菜单中的技能菜单](/img/fRfyPzx7WE2fS-my/1755354172779-587c6aec-8e40-4fd8-9760-121931a63357-713674.png)

打开服务器菜单后，左键点击==第二行第八格==，即可进入技能菜单

![技能菜单](/img/fRfyPzx7WE2fS-my/1755354211997-fac96f5b-cf36-4312-8dbc-92d3f0bd48ba-643635.png)

你在服务器中不同的行为都可以让你在不同的领域中升级，且随着你在该领域的不断升级，都可以==获得一些技能==，可以==根据技能的提示==进行使用。

点击进入某个领域，你就可以知道你在这个领域的成长状况

![成长状况查看](/img/fRfyPzx7WE2fS-my/1755354302952-a46ddb94-1dbb-42c5-a4ff-c5e7d478441f-599945.png)
