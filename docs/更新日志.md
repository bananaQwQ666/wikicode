# 更新日志

1. 2019年7月，BananaFansCraft服务器(云琉世界的前身，简称BFC)正式立项，确立服务器版本为Minecraft1.14.4，并确立服务器主城为第一版主城。
2. BFC服务器升级到Minecraft1.15.2。
3. BFC服务器升级到Minecraft1.16.1，并确立服务器主城为第二版主城。
4. 服务器改名为“YunLiuCraft云琉世界”。
5. 云琉世界二周目正式开服，服务器升级至Minecraft1.18.2，并确立服务器主城为第三版主城。
6. 由于服务器出现性能性漏洞以及刷钱BUG，被迫宣布进入无限期停服。
7. B站up主@Shu树儿- 改造了服务器主城，更加美观，并且更加符合赛博风特色。
8. 服务器更换了CPU为i5-11400的机器。
