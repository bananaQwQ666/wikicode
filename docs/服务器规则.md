## 云琉世界群聊守则（2026.8）

欢迎加入云琉世界！你可以在这里结识朋友、日常闲聊，也请自觉遵守以下规定，共同维护良好的群聊氛围。

---

### 一、 极重违规

触犯以下任意条目者，管理组将直接给予 **踢出群聊** 或 **永久封禁** 处分：

1. **违规言论**  
   发布反社会、反法律、涉暴涉毒以及政治敏感言论。

2. **网络安全威胁**  
   恶意传播木马病毒、吓人链接，或公开讨论与提供黑客攻击工具。

3. **侵犯个人隐私**  
   恶意人身攻击、人肉搜索或公开他人隐私。

4. **违规宣传**  
   未经许可，在群内公开宣传其他同类游戏服务器。

---

### 二、 重度违规

触犯以下任意条目者，处以 **长期禁言（24小时起）** 或 **踢出群聊** 处分：

1. **不良信息**  
   公开发布涉黄、赌博等违法/不良信息。

2. **私自线下交易**  
   未经允许，私自以现实金钱交易服务器内的虚拟资产。

3. **恶意欺诈**  
   故意误导、坑害或欺诈新玩家。违者须向当事人诚恳道歉并补偿全部损失。

4. **歧视、拉踩与引战**  
   发表种族、性别等各类歧视言论；跨平台或跨服务器挑起矛盾、故意造谣起哄破环社区气氛。

---

### 三、 一般违规

触犯以下任意条目者，处以 **警告** 或 **短期禁言（5分钟至2小时）** 处分：

1. **破坏讨论环境**  
   刷屏、恶意斗图、阴阳怪气或频繁刷无意义梗。

2. **群内争吵**  
   在群内公开吵架与人身谩骂，个人矛盾请私聊解决。

3. **不当言行举止**  
   恶意炫耀硬件配置、拿他人痛处开过分玩笑，或公开向管理员无理索要游戏物资。

4. **违规名片**  
   使用高仿他人、广告宣传或包含控制字符的群名片。

5. **违规群昵称**  
   群昵称包含不当内容者，经管理提醒后不修改，将 **直接踢出**。

---

### 四、 管理员行为规范

管理员须带头遵守群规，并接受全体群员监督：

1. **严禁滥用职权**  
   禁止无故禁言、踢人或欺负群友。违者暂停管理权限7至14天，情节严重者撤销管理员职务。

2. **违规处理**  
   管理员触犯群规将记录在案，须公开道歉并由管理组与群主共同投票，决定后续职务留任。
