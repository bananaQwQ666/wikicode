## <font>保持友好的游戏氛围!</font>
## <font>使用恰当的词语</font>
+ <font>不要使用粗俗的语言，例如诅咒、辱骂、人身攻击</font>
+ <font>请避免使用他人无法理解的词语缩写</font>
+ <font>不允许使用被认为不恰当/不合适词语的用户名</font>
+ <font>请保持对其它玩家的基本礼貌</font>
    - <font>营造良好的游戏氛围不仅需要全体玩家共同遵守规则、互相监督，也需要丢掉戾气、宽以待人</font>
+ <font>YunLiuCraft是一个公开的服务器，每个人都有权发表自己的意见。您不应因意见不同就对他人公开表达不满</font>
+ <font>不刷屏</font>
    - <font>发送具有基本内容重复的标点符号、词语、句子、消息、广告等</font>
    - <font>滥用颜色、样式</font>
    - <font>滥用其他会发送公屏信息的功能</font>

### <font>惩罚措施：禁言 或 警告</font>
## <font>不讨论不恰当、有争议性的话题</font>
+ <font>包括但不限于：</font>
    - <font>有关政治敏感的</font>
    - <font>对他人进行性暗示、性骚扰的</font>
    - <font>对特定人或人群进行人身攻击的</font>
    - <font>展开针对所处地域的地域攻击的</font>
    - <font>未经证实的言论；谣言；破坏社会稳定的</font>
    - <font>有关非法组织的</font>
    - <font>试图分裂国家与民族的</font>
    - <font>引起玩家对立、引战话题的</font>
    - <font>谈论或者实施性别歧视的</font>
    - <font>发布种族主义/种族歧视相关话题的</font>
    - <font>谈论有关心理健康方面的</font>
    - <font>反对宪法所确定的基本原则的</font>
    - <font>危害国家安全，泄露国家秘密，颠覆国家主权，破坏国家统一的</font>
    - <font>损害国家荣誉和利益的</font>
    - <font>煽动民族仇恨、民族歧视，破坏民族团结的</font>
    - <font>破坏国家宗教政策，宣扬邪教和封建迷信的</font>
    - <font>散布淫秽、色情、赌博、暴力、凶杀、恐怖或者教唆犯罪的</font>
    - <font>侮辱或者诽谤他人，侵害他人合法权益的</font>
    - <font>违反法律法规底线、社会主义制度底线、家利益底线、公民合法权益底线、社会公共序底线、道德风尚底线和信息真实性底线的“条底线”要求的</font>

### <font>惩罚措施：封禁(永久)</font>

+ <font>包括但不限于：</font>

    - <font>作弊Mod</font>
