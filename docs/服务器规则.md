# 服务器规则

> 欢迎加入云琉世界！为了给全体玩家提供轻松、友好、公平的游戏与交流环境，请自觉遵守以下玩家条约及群聊守则。

---

## 云琉世界玩家条约

### 序言
欢迎加入云琉世界！本服旨在为玩家提供轻松友好的游戏与交流环境。加入本服即视为同意遵守本条约。管理团队对本条约拥有解释权，并有权对违规行为采取相应措施。你可以在这里结识朋友、日常闲聊，也请自觉遵守以下规定，共同维护良好的游戏社区氛围。

### 一、永久封禁
出现以下行为之一的，将被永久封禁账号且不予申诉：

- 发布或传播违反中国法律法规的内容，包括但不限于危害国家安全、分裂国家、煽动民族仇恨、宣扬恐怖主义、极端主义、邪教或封建迷信。
- 发布或传播淫秽、色情、赌博、暴力、凶杀信息，或教唆犯罪、侮辱诽谤他人、侵害他人合法权益。
- 发布或传播谣言，扰乱社会秩序，破坏社会稳定。
- 讨论或实施性别歧视、种族歧视、地域攻击等针对特定人群的侮辱性言论。
- 使用作弊客户端、破坏平衡性的模组、辅助软件或地图逆向工程工具。
- 利用游戏恶性 BUG 或服务器漏洞，包括物品复制、NBT 溢出攻击、卡服崩服等。
- 对其他玩家实施人肉搜索、网络暴力或严重人身攻击。

### 二、封禁或警告
出现以下行为之一的，视情节轻重给予警告或临时封禁处理：

- 破坏他人建筑或设施。
- 未经许可盗窃他人容器内的物品。
- 在非 PVP 区域未经许可击杀其他玩家或设置针对其他玩家的伤害陷阱。
- 恶意 PVP 或干扰其他玩家正常游戏。
- 非故意利用游戏漏洞但经管理员提醒后拒绝停止。
- 滥用服务器资源，制作或运行卡服、崩服机器。
- 使用带有歧视性、侮辱性或冒充性质的游戏 ID 或群昵称。
- 使用作弊客户端、破坏游戏平衡性的模组、辅助软件和可能造成版权问题的工具（详情见第五条附则）。

### 三、警告或禁言
出现以下行为之一的，视情节轻重给予警告或临时禁言处理：

- 在群内或游戏公屏刷屏，发送三次及以上重复消息、无意义内容或滥用颜色样式。
- 使用粗俗语言，辱骂、嘲讽他人，或进行人身攻击。
- 因意见分歧在公开场合对他人进行贬损或引战。
- 恶意炫耀硬件配置、游戏进度或其他攀比性内容。
- 发布不恰当的玩笑或恶意误导新人。
- 公开讨论与本服无关的其他服务器或平台矛盾。

### 四、附则
- 本条约对所有玩家及管理人员同等适用。
- 管理人员滥用职权者，经核实后将降职或取消管理权限。
- 账号所有者对账号下所有行为负责。若账号被盗，请立即联系管理团队冻结。
- 因利用游戏漏洞或违反条约所造成的损失，由违规者自行承担。
- 管理团队有权根据实际情况对违规行为进行裁定，处罚措施不限于上述类别。

### 五、作弊行为的说明
包括但不限于：
- 各类作弊客户端
- 作弊 Mod
- 透视资源包
- DLL 注入的外部辅助软件
- 内存修改器（如 CheatEngine）
- 时钟调整工具（如 加速齿轮）
- 会影响服务器整体稳定运行或者他人游玩体验的自动脚本
- 服务器地图逆向工程工具，以计算种子或者直接发现矿物、结构、刷怪笼、遗迹、要塞、地牢、宝藏、战利品表等的辅助工具、补丁、模组或者外部软件（如 SeedCracker 等）
- 滥用辅助模组的特定功能（例如 Tweakoo 的特定功能等会在服务器产生实际影响的、破坏平衡性的）
- 滥用地图下载器或具备类似功能的 Mod、辅助工具、补丁
- 使用任何恶性 BUG 包括但不限于：
  - 利用地图 Marker 导致客户端严重卡顿
  - NBT 溢出攻击
  - 恶意物品复制（如铁砧复制等）
  - 其他被认为是严重影响游戏平衡性的行为
- 滥用服务器资源
  - 使用卡服与崩服机器
- 其他管理员商议后，认为不合理的行为

## 云琉世界群聊守则

欢迎加入云琉世界！你可以在这里结识朋友、日常闲聊，也请自觉遵守以下规定，共同维护良好的群聊氛围。

### 一、极重违规
触犯以下任意条目者，管理组将直接给予 **踢出群聊** 或 **永久封禁** 处分：

1. **违规言论**  
   发布反社会、反法律、涉暴涉毒以及政治敏感言论。
2. **网络安全威胁**  
   恶意传播木马病毒、吓人链接，或公开讨论与提供黑客攻击工具。
3. **侵犯个人隐私**  
   恶意人身攻击、人肉搜索或公开他人隐私。
4. **违规宣传**  
   未经许可，在群内公开宣传其他同类游戏服务器。

---

### 二、重度违规
触犯以下任意条目者，处以 **长期禁言（24小时起）** 或 **踢出群聊** 处分：

1. **不良信息**  
   公开发布涉黄、赌博等违法/不良信息。
2. **私自线下交易**  
   未经允许，私自以现实金钱交易服务器内的虚拟资产。
3. **恶意欺诈**  
   故意误导、坑害或欺诈新玩家。违者须向当事人诚恳道歉并补偿全部损失。
4. **歧视、拉踩与引战**  
   发表种族、性别等各类歧视言论；跨平台或跨服务器挑起矛盾、故意造谣起哄破坏社区气氛。

---

### 三、一般违规
触犯以下任意条目者，处以 **警告** 或 **短期禁言（5分钟至2小时）** 处分：

1. **破坏讨论环境**  
   刷屏、恶意斗图、阴阳怪气或频繁刷无意义梗。
2. **群内争吵**  
   在群内公开吵架与人身谩骂，个人矛盾请私聊解决。
3. **不当言行举止**  
   恶意炫耀硬件配置、拿他人痛处开过分玩笑，或公开向管理员无理索要游戏物资。
4. **违规名片**  
   使用高仿他人、广告宣传或包含控制字符的群名片。
5. **违规群昵称**  
   群昵称包含不当内容者，经管理提醒后不修改，将 **直接踢出**。

---

### 四、管理员行为规范
管理员须带头遵守群规，并接受全体群员监督：

1. **严禁滥用职权**  
   禁止无故禁言、踢人或欺负群友。违者暂停管理权限 7 至 14 天，情节严重要撤销管理员职务。
2. **违规处理机制**  
   管理员触犯群规将记录在案，须公开道歉并由管理组与群主共同投票，决定后续职务留任。
