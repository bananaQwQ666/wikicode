# 环球市场

![菜单中的环球市场入口](/img/7UE1jVbfpccyea4H/1755411106996-94a19517-5cc3-48aa-a0fb-8e095c460827-196445.png)

打开服务器菜单，左键点击==第二行第六格==即可进入环球市场

![环球市场界面](/img/7UE1jVbfpccyea4H/1755411216039-c0b29613-8006-4955-b206-3ba70f20eb3e-352011.png)



这里是一些基础指令的教程，包括出售手中的物品、发起手中物品收购、发起新的拍卖等。

最下面一行的箱子为==个人邮箱==入口，在这里可以看到别人的赠送以及购买、出售、下架等邮件

而指南针则是所有==玩家商店==的入口，进去后，可以看到其他玩家创建的个人商店

### 购买其他玩家出售的物品或参与其他玩家的收购
其他玩家上架物品后，商品会显示在环球市场的主界面

![主界面中其他玩家出售的商品](/img/7UE1jVbfpccyea4H/1755414710122-35bf301b-eac2-48d2-b38f-7f578627bb86-915966.png)

选择自己需要购买的商品，或者自己需要参与的收购，根据提示操作即可

![参与收购](/img/7UE1jVbfpccyea4H/1755414876210-d516cb61-bdc1-41de-a17b-3ca2f0a2f247-023539.png)

![成功后的提示](/img/7UE1jVbfpccyea4H/1755414899951-e659a6ff-3385-4a8d-a76e-65f50b520b42-290697.png)



### 上架自己的商品或者收购
![基础指令和操作教程](/img/7UE1jVbfpccyea4H/1755413892865-6594c65b-ebec-44d4-a187-b50fa0a81dad-983432.png)

回到主界面，点击最顶上的==玩家头颅==，进入个人档案页面

![个人商家档案页面](/img/7UE1jVbfpccyea4H/1755414100238-9a286d37-7f44-4c99-8ae0-c9fdaa875f93-599088.png)

**在这里可以调整**一些自己作为商家的设置

**刷新商家缓存**——刷新自己的档案数据

**设置商店简介**——如果玩家从“个人商店”页面看到你的商店，你设置的简介就会显示在上面，如果你的简介足够有特色，就能吸引到客户

**设置商店名字**——同上条

**隐藏商品**——状态改为是后，你的商品不会在环球市场上显示，其他玩家需要通过个人商店页面进入你的商店，才能看见你的商品

**隐藏商家名字**——玩家没有权限

**打烊商店**——状态改为是后，你的商店会在个人商店页面消失

**设置商品排序、设置邮件排序**——道理都差不多![设置商品排序](/img/7UE1jVbfpccyea4H/1755415208781-baf25e8d-3f6e-4dcb-819f-6aedc19d93f1-381220.png)

**上锁邮箱**——上锁后，你将无法收到其他玩家给你邮寄的物品
