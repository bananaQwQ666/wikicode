# 皮肤系统

皮肤系统非常简单，只需要掌握以下几个指令稍等

==注意：设置皮肤有冷却==

### 使用正版玩家的皮肤
> /skin 玩家ID
>

即可将自己的皮肤更换为对应ID玩家的皮肤

例如：/skin W_Tsen

![已成功换成W_Tsen的皮肤](/img/W0VvsiCY3sTt5vSp/1755406137566-ad81abb9-7ecc-4025-af51-cc187f53e461-641365.png)

### 使用URL皮肤
首先，你需要先准备好皮肤文件的URL

然后在游戏中输入以下指令

> /skin url 皮肤文件URL
>

即可设置

### 恢复初始皮肤
> /skin clear
>
