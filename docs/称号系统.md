# 称号系统

### 称号商城
![菜单中的称号商店入口](/img/TRJ_uzSh5rnBshxt/1755336528969-cd6e6527-f396-4a1d-9f53-da9f261dbf7d-642471.png)

打开服务器菜单后，左键点击==第三行第三个==即可进入称号商店。

![称号商城界面](/img/TRJ_uzSh5rnBshxt/1755336711215-1751d8df-3c16-4c99-b129-9dba62064415-059167.png)

这些命名牌就是商城在出售的称号了，只要您的蕉币数量足够，那么==左键点击==你想要的称号，即可实现购买，将喜欢的称号收入自己的仓库(但是称号的价格较为昂贵，一般为500-2000蕉币，==前期不建议购买==。当然如果您是UP主等，可以寻找管理员申请![1755337000067-1b5d0137-c6fe-4a33-91cd-2864afaee3d3.png](/img/TRJ_uzSh5rnBshxt/1755337000067-1b5d0137-c6fe-4a33-91cd-2864afaee3d3-985304.png)称号。如果您给服务器累计赞助超过100元，那么可以寻找管理员申请自定义称号，支持颜色符号)



接下来介绍最底下一行的功能，==铁砧图案==为自定义称号，点击后在聊天框输入自己想要的称号(支持颜色符号)，Enter确认后进入支付页面，此时前两个支付方式都没有用，需要点击第三个，==支付3000蕉币后==，即可获得这个自定义称号。当然，如果您给服务器==累计赞助超过100元==，那么可以寻找管理员申请自定义称号，无需耗费蕉币。

两个磁力诱饵图案分别是==上一页、下一页==

指南针图案为“==根据类型搜索==”，==暂时没有什么用==，因为目前商城里的所有称号都是金币支付类型的。

屏障图案是==返回==

### 称号仓库
左键点击==工作台图案==，即可进入自己的称号仓库

![称号仓库页面](/img/TRJ_uzSh5rnBshxt/1755337396826-f2a359b3-8c09-46e8-a140-514a6ec32e09-140550.png)

在这里您可以看见自己所拥有的所有称号(如果加入了公会那么还会有公会称号)，==左键点击==对应称号即可应用

![应用了称号的效果(第三个中括号内就是称号)](/img/TRJ_uzSh5rnBshxt/1755337485924-0275c2ed-0b5a-4198-aa36-e27dadf308ce-169360.png)

最底下的==末影箱==图案，==左键==点击可以再次回到称号仓库。

金锭图案==暂时没什么用==，==不需要去点==。
