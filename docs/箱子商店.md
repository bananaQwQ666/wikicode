# 箱子商店

### 购买箱子商店里的物品
对着一个箱子商店点击==鼠标左键==，左下角就会收到提示

![左键箱子商店收到的提示](/img/zL4C3hBVt3z1uRfj/1755416409275-4581dfa3-5e80-47fd-94a6-fc8fb40b6055-853549.png)

此时，在聊天框里输入==想要购买的数量==，并回车，就购买成功了

![购买成功的提示](/img/zL4C3hBVt3z1uRfj/1755416462137-e6dade54-8c68-443a-9278-ffff4fd459ae-229680.png)

### 创建箱子商店
![正在创建商店](/img/zL4C3hBVt3z1uRfj/1755415460487-3709f987-9031-4790-bb1f-f2ec1c202329-560923.png)

首先要放置一个箱子(大箱子也可以)，然后手持自己需要出售的商品，在聊天框输入==/qs create 想卖的价格==，就可以实现商店的创建

![完成创建的商店](/img/zL4C3hBVt3z1uRfj/1755415554903-c83d1035-e298-4876-8720-6e8c9ce67b77-246371.png)

创建完商店后，你的商店会提示你缺货，那是因为你还没有供货

此时，你只需要打开箱子，==把商品放进去==(注意，补货的商品必须和创建时手持的商品一模一样，否则还是缺货)，就会==显示有货==了

![在商店里放入了商品](/img/zL4C3hBVt3z1uRfj/1755415929079-c59b4609-3148-492f-aedb-1224d7657d2e-405824.png)

![补货后的商店](/img/zL4C3hBVt3z1uRfj/1755415936338-fe66f1b4-004e-4c57-8f26-0ba34a4100de-554890.png)

什么？箱子空间不够？没事，你可以使用漏斗和仓库箱子，但是一定要保护好仓库箱子，加上箱子锁。但是，加上了箱子锁后，漏斗无法漏出东西，此时，你就需要在大箱子旁边再放一个告示牌，他会自动加上[redstone]，就可以使用了，在这之后千万不能打开这个告示牌的修改页面，否则对红石的支持就会失效。

![受到保护的箱子和漏斗](/img/zL4C3hBVt3z1uRfj/1755416179816-47a7188b-ffda-4887-98b8-ad3f53e5110b-206540.png)

当有玩家购买了你商店里的东西时，就会收到这样的提示，系统会==收取一定的手续费==

![1755416492013-227a9098-25f5-474a-819f-07547c66161b.png](/img/zL4C3hBVt3z1uRfj/1755416492013-227a9098-25f5-474a-819f-07547c66161b-406127.png)

这些手续不会到任何人的口袋里，只是会被服务器扣除
