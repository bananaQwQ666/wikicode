# 箱子锁

本服安装了箱子锁插件，而且箱子锁插件==不止可以锁箱子==，还可以锁==木桶、潜影盒、门、漏斗、熔炉、栅栏门、活板门==

![能上锁的物品](/img/rcS9hXWEYJFDdprK/1755404138308-8377ddee-74e7-4fc7-875f-7fbe832594f2-240314.png)

只需拿着告示牌，对着需要上锁的物品==右键放置==，成功放置后，会自动为你上锁。如果你想添加其他玩家，只需要对准告示牌右键，在你的名字下方加上那个玩家的ID即可；如果你需要==添加更多的玩家==，就需要在这个物品的其他面上放更多的告示牌，并且按以下格式输入(括号为英文括号)

> (更多用户)
>
> 玩家ID
>

![添加更多用户的告示牌](/img/rcS9hXWEYJFDdprK/1755404699227-71377421-b35d-4818-aae8-73bd9d1987db-428999.png)

这样，在这个告示牌上被写上名字的玩家也可以使用该上锁物品。



如果拿着告示牌对物品右键，没有成功放置怎么办？

没关系，只需要拿着告示牌对着物品==Shift+右键==，在告示牌==第一行==写下

> (私有)
>

括号依旧是英文括号，确认后，系统会自动补全你的游戏ID。

如果你在告示牌上删除了自己的ID，那你就打不开了，所以==千万不要删除或者修改自己的ID==



在上锁的大箱子旁边再放一个告示牌，他会自动加上[redstone]，就可以和红石一起用了(包括漏斗什么的)，但是在这之后千万不能打开这个告示牌的修改页面，否则对红石的支持就会失效。
