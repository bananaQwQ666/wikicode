# 语音聊天

由于本服为社交向服务器，所以我们提供了语音聊天系统。玩家使用服务器专用客户端进入，客户端自带了语音聊天配套mod。你进入服务器后，可以直接连接到服务器的语音服务器。



服务器语音默认为<font style="background-color:#ff5847;">音量触发</font>，你也可以调成按键触发

![说话时左下角的提示](/img/BjL1rZ2C1HfTPOdx/1755406978165-00381cc2-045d-40b2-bba6-b61a0f81dc58-715482.png)

客户端默认的语音通话设置按键为<font style="background-color:#ff5847;">V键</font>

![按下V键后，打开的语音设置](/img/BjL1rZ2C1HfTPOdx/1755407060632-753590ed-e6a5-44de-b891-6e98c32344b7-897213.png)

上面两个大按钮，左边的设置点进去，就可以按自己的偏好去设置了。右边的群组是让你可以自己创建语音群组，<font style="background-color:#ff5847;">由于全局聊天时，只有靠近发言者，才能听见发言者说话，随着距离的增加，音量也越小，直至听不见，所以群组就能很好的解决这个问题，只要玩家在同一个群组里，那么无论相隔多远，都可以听见发言。</font>



下面的按键，左边的三个分别是：麦克风静音，扬声器静音，音量调整

右边的两个分别是：录音，隐藏语音聊天图标



![1755407306991-610dd373-6bb0-4eb2-a6ad-05e6ae421ea7.png](/img/BjL1rZ2C1HfTPOdx/1755407306991-610dd373-6bb0-4eb2-a6ad-05e6ae421ea7-358986.png)

如果设置了按键触发，那么你需要在<font style="background-color:#ff5847;">ESC-选项...-按键控制...-按键绑定...</font>中寻找到以上内容，将”<font style="background-color:#ff5847;">通话键</font>“改为你觉得方便的按键即可。
