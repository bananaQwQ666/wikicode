# 载具系统

### 购买与使用载具
![载具商店的位置](/img/79rldAkeLEgP9FHh/1755416817580-1b888f7a-b174-496e-bd15-82d9521e005b-763266.png)

![载具商店](/img/79rldAkeLEgP9FHh/1755416847751-f33dbe1d-ce7e-4b1a-b369-5117260ccced-027921.png)

在主城地图的这个位置，可以找到<font style="background-color:#ff5847;">载具商店</font>，(可以传送到“瓷溪川小镇”这一地标，就可以在旁边寻找到载具商店)，里面有各种各样的载具。你只需要在后面一排的箱子商店中，<font style="background-color:#ff5847;">购买</font>自己想要的载具就可以了


![购买后的获得物](/img/79rldAkeLEgP9FHh/1755416918626-ca39175a-9b8c-4cb4-9b39-e4e86641ad1f-219490.png)

购买后，你会获得一个这样的物品，这就是你的载具了，拿着它，<font style="background-color:#ff5847;">在地上放置</font>即可

![放置出来的车辆](/img/79rldAkeLEgP9FHh/1755419691502-7941c32b-0a22-418c-a8ec-a5df48a82c0c-338225.png)

<font style="background-color:#ff5847;">右键</font>你的载具，就可以坐上去了。想要下车只需要按下左Shift

在车上对载具<font style="background-color:#ff5847;">右键</font>，可以打开载具后备箱

![载具后备箱](/img/79rldAkeLEgP9FHh/1755420069893-693b2d9e-4edf-4645-8674-2d8accd0a421-112062.png)

下车后，对着载具<font style="background-color:#ff5847;">Shift+右键</font>，就可以把载具收到背包里

### 如何给载具加油
当你行驶时，任务栏上方的Actionbar位置会闪烁这样一个东西，这就是载具的油量，当油量不足时，需要加油

![油量表](/img/79rldAkeLEgP9FHh/1755419860902-0c7e5dce-67a8-4b76-9eb2-ea6d6a73873e-764820.png)

下车，对着载具<font style="background-color:#ff5847;">Shift+左键</font>，即可进入油箱管理

![在这里可以看到燃料剩余量](/img/79rldAkeLEgP9FHh/1755420142398-d19ba186-dec2-4df8-9f7e-36c59f119eb6-613505.png)

### 飞机如何起飞
从服务器一周目开始，就一直有人问我飞机如何起飞，在这里我教大家。

首先，你需要有一段足够长的<font style="background-color:#ff5847;">跑道</font>。上飞机后，按住<font style="background-color:#ff5847;">W+空格</font>，视角向上抬，飞机行驶一段距离后，飞机的轮子会收起，随后就可以成功起飞
