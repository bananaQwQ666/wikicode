# 领取属于自己的地皮

进入服务器菜单后，左键点击==第三行最后一个==进入世界传送页面![菜单中的世界传送入口](/img/a9fZiGWdo4ST68RZ/1755337696894-b293a545-f043-4a17-931f-38a8402230b6-271733.png)

进入后，左键点击==地皮世界==即可传送至地皮世界。

![地皮世界](/img/a9fZiGWdo4ST68RZ/1755337849892-c8430dc1-bdc7-4db1-bae3-35f57226d3f0-029051.png)

输入==/plot auto==即可自动认领地皮，认领后您会被传送到您的地皮。

或者，您可以走进一片你想要的地皮，输入==/plot claim==进行认领，当然前提是这个地皮没被别人认领过，那么，如何判断一块地皮有没有被别人认领呢？很简单，只需要观察这块地皮的边界，如果它的边界是白色羊毛，那么说明它没被认领；如果是绿色羊毛，那说明已经被认领了，那你就只能寻找另外一块没被认领的地皮了。

![确认一块地皮是否被认领的方法](/img/a9fZiGWdo4ST68RZ/1755339129373-a9fc19ff-35d6-406f-91e5-aecfcfbd6d0c-537200.png)



以后如何传送到自己的地皮呢？只需输入==/plot home==即可
