# 领地系统

想对自己的基地进行保护？使用领地系统就可以了！

本服的圈地标记工具为==木锄==，使用木锄圈好两个点(==如图，白色为需要圈的区域，青色的两个方块是你需要圈的，用木锄对着其中一个点左键，再对着另一个点右键即可==)

![圈地示意图](/img/XnwmZ2IKVjr0gOOs/1755409894826-578657db-5102-4637-a62a-a0c352db89df-549450.png)

圈完之后，物品栏上方会告诉你圈地需要的金额，确定好你有足够的蕉币，站在你圈地的范围内，输入==/res create 领地名字==即可

创建完之后，输入==/res set==即可进入领地权限编辑页面，根据自己的需要进行编辑就可以了

![领地权限编辑页面](/img/XnwmZ2IKVjr0gOOs/1755410180142-916be77d-276f-4c92-9e70-36f2da3e6c1a-033399.png)

输入==/res message 领地名 enter或者leave 消息内容==，可以设置其他玩家进入该领地时会收到的提示

想要删除这个领地，只要输入==/res remove==，再输入==/res confirm==即可删除(注意，圈地消耗的钱不会归还)
