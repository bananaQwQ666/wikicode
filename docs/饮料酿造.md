# 饮料酿造
茶需慢慢摇，心急则味散~

## 饮品酿造
### 可以在哪酿造？
1.可以前往西街 暖雪居 围炉煮茶店
![](/img/brew/1-3.png)

2.也可以自己搭建酿造台(见下)

### 搭建酿造台
![](/img/brew/1-4.png)

如图，左边是用于蒸煮酿造的炼药锅的两种形式，两种形式皆可(下界岩+火 或者 篝火)

右边则是用于蒸馏的酿造台 (如果饮品在配方里没有标注蒸馏步骤，则不需要)

### 开始酿造
首先，所有的饮品都需要先在炼药锅进行酿造。

1.向炼药锅中添加水；

2.手持需要的原料对炼药锅右键，添加原料，直到达到配方中的数量；

3.手持时钟对炼药锅右键，会在聊天框提示蒸煮时间，同时准备好玻璃瓶；
![](/img/brew/1-5.png)

4.酿造时间到，及时手持玻璃瓶右键将其盛装，注意不要超时。

### 蒸馏(如果需要)
1.确认自己正在酿造的饮品是否需要蒸馏。如果不需要，则可直接饮用；若需要，则进行蒸馏；

2.蒸馏需要在酿造台中放入萤石粉(蒸馏不会消耗萤石粉)，随后放入饮品，等待蒸馏；
![](/img/brew/1-6.png)

3.注意蒸馏次数，蒸馏次数满后会自动停止，如果未满便取出，饮品可以正常饮用，但等级和效果都会减弱。
![](/img/brew/1-7.png)

## 酒桶
![](/img/brew/1-1.png)
> 小型酒桶
长2宽2高2，需建材: 木楼梯*8

![](/img/brew/1-2.png)
> 大型酒桶
长4宽3高4，中空，需建材: 木板*18，木楼梯*16，木栅栏*5

::: danger 注意
两种酒桶都一定要贴一个木牌写上“酒桶”并提示贮藏桶创建成功才可用

要使用，右键打开即可
:::
